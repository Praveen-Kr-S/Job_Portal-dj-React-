# Job Portal System – Django & React

## Overview

A full-stack Job Portal web application developed using Django REST Framework (DRF) and React.js.

The system allows recruiters to post jobs and job seekers to search and apply for jobs through a modern web interface.

---

# Features

## Authentication & Authorization
- User Registration & Login
- JWT Authentication
- Role-Based Access Control
- Recruiter and Job Seeker Modules

## Recruiter Features
- Post New Jobs
- Update/Delete Job Listings
- View Applicants
- Manage Posted Jobs

## Job Seeker Features
- Browse Available Jobs
- Apply for Jobs
- View Application Status
- Profile Management

## Backend Features
- RESTful API Development
- CRUD Operations
- Secure Authentication System
- Database Integration using PostgreSQL/MySQL

## Frontend Features
- Responsive UI using React.js
- API Integration with Django Backend
- Dynamic Components
- Modern UI Design

# Installation

## Backend Setup

```bash
git clone https://github.com/Praveen-Kr-S/Job_Portal-dj-React-.git

cd backend

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
